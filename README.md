# ![Logo](https://animes-online-angular.vercel.app/assets/icons/logo.svg) AnimeOnline
This aplication is primary aim is to serve as a practical platform for me to enhance my front-end development skills. Leveraging **[Typescript](https://www.typescriptlang.org/)** as the primary language, **[Angular](https://angular.io/)** as the front-end framework, **[Sass](https://sass-lang.com/)** for CSS preprocessing, and ensuring robust unit test coverage with **[Jasmine](https://jasmine.github.io/index.html)** and **[Karma](https://karma-runner.github.io/6.3/index.html)**, this project underscores my commitment to mastering these technologies. Deployment is facilitated through the [Vercel](https://vercel.com/)** platform, streamlining the CI/CD pipeline for seamless updates.
